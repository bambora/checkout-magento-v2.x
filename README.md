# Worldline Online Checkout for Magento 2

## System Requirements

### PHP Version

* PHP ~8.2.0, ~8.3.0, ~8.4.0, or ~8.5.0

## Supported Magento 2 versions

* **Magento 2.4.6 and later** (2.4.6, 2.4.7, 2.4.8, 2.4.9+)
* Full support for all Magento 2.4.6+ releases
* Earlier versions (2.1.x, 2.2.x, 2.3.x, 2.4.0-2.4.5) are no longer supported

## Included Payment Gateway

* Worldline Online Checkout
